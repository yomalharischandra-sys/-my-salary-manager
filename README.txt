MY SALARY MANAGER — starter PWA

Files:
- index.html: app
- manifest.webmanifest + sw.js + icons: install/offline support

IMPORTANT:
1. This app stores data in the browser's local storage on the device. It does not send bank credentials or transactions to a server.
2. To install as a PWA, publish the contents of this folder to an HTTPS static host (for example, a static website host), then open the site in Chrome on Android and choose Install app / Add to Home screen.
3. Open the same hosted URL on a laptop for the web version. Data is not automatically shared between devices. Use History & backup > Export backup / Import backup to move data manually.
4. Starting amounts are the salary allocations supplied: BOC 38,000; Commercial Bank 15,000; People's Bank 22,000. People's Bank pockets are allocations within that 22,000, not extra funds.
5. This is a personal budgeting tool, not connected to bank accounts. Enter transactions manually.
